# Ours Archive

**연애·결혼·임신출산·육아를 하나의 타임라인으로 잇는 커플/가족 아카이브 PWA**

우리 둘의 모든 순간을, 한 페이지에 담아요.

서비스 https://ours-archive.vercel.app
(폐쇄형 서비스...ㅠ)

---

## 왜 만들었나

커플의 기록은 단계마다 다른 앱으로 흩어집니다. 연애는 커플 앱, 결혼 준비는 스프레드시트, 임신은 육아 앱. 인생은 이어지는데 기록만 끊깁니다.

결혼 준비는 체크리스트와 일정과 예산이 따로 놀아서 같은 항목을 세 번 관리하게 되고, 가족에게 사진을 공유하려면 단톡방에 뿌리는 방법뿐이라 공개 범위를 통제할 수 없습니다.

**한 서비스 안에서 챕터를 이어가고, 공개 범위를 서버가 강제하는 아카이브**를 목표로 만들었습니다.

---

## 핵심

### 1. 접근 통제를 서버에 둠

권한 판정을 화면이 아니라 **Postgres 행 수준 보안 정책**에서 수행합니다. 메뉴를 숨기는 것은 보조 수단일 뿐이라, 주소를 직접 입력하거나 클라이언트를 조작해도 서버가 데이터를 내주지 않습니다.

챕터마다 공개 범위가 다릅니다. 연애와 결혼과 임신은 부부만, 육아는 가족까지.

### 2. 결혼 준비를 단일 레코드로 통합

준비 항목 하나가 체크리스트·일정·예산 속성을 **선택적으로** 가집니다. 어느 탭에서 수정해도 같은 레코드를 고치므로 모든 화면이 자동으로 맞춰집니다.

진행률과 예산 사용률, D-DAY는 저장하지 않고 조회할 때마다 계산합니다. 그래서 결혼 날짜 하나만 바꿔도 관련 표시가 전부 따라옵니다.

### 3. 일정 확인 리마인더

일정을 올려도 상대가 확인하지 않는 실사용 문제에서 나온 기능입니다.

1. 일정 등록 시 **확인 요청 대상 역할**을 지정
2. 지정 역할의 구성원에게 발송하되 등록자 본인은 제외
3. 미확인이 지속되면 6시간, 12시간, 24시간, 이후 24시간마다 단계적으로 발송
4. 대상자가 해당 일정에 댓글을 달면 즉시 중단

외부 푸시 서비스 없이 표준 Web Push와 데이터베이스 예약 실행만으로 구성했습니다.

### 4. 하나의 기록, 여러 화면

같은 기록이 피드와 달력과 지도에 서로 다른 모습으로 나타나되, 상세 화면은 하나입니다. 어디서 열어도 결과가 같고 주소로 공유할 수 있습니다.

## 기술 스택

| 레이어 | 선택 |
| --- | --- |
| 프론트엔드 | React, TypeScript, Vite |
| PWA | vite-plugin-pwa, 서비스워커 직접 작성 |
| 상태관리 | React Query |
| 백엔드 | Supabase — Postgres, RLS, Auth, Storage, Edge Functions |
| 예약 실행 | pg_cron, pg_net |
| 인증 | 카카오 OAuth |
| 지도 | 카카오맵 JS SDK |
| 푸시 | Web Push (VAPID) |
| 호스팅 | Vercel |

별도 API 서버를 두지 않습니다. 클라이언트가 데이터베이스에 직접 붙고 권한은 정책이 판정합니다.

## 실행

```bash
git clone https://github.com/ji092/OursArchive.git
cd OursArchive
npm install
npm run dev
```

`.env` 파일에 아래 값이 필요합니다.

```
VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY
VITE_KAKAO_JS_KEY
VITE_VAPID_PUBLIC_KEY
```

데이터베이스는 `backend/migrations/` 와 `backend/policies/` 의 SQL을 번호 순서대로 실행해 구성합니다.

| 명령 | 설명 |
| --- | --- |
| npm run dev | 개발 서버 |
| npm run build | 타입 검사 후 빌드 |
| npm run typecheck | 타입 검사만 |

## 구조

```
src/
  app/          라우터, 레이아웃, 접근 가드
  pages/        경로별 화면
  features/     챕터별 도메인 로직 (love, wedding, pregnancy, baby, admin)
  shared/       공용 컴포넌트, 권한 판정, 저장소, 스케줄, 푸시
backend/
  migrations/   스키마
  policies/     행 수준 보안 정책
  functions/    Edge Function
```

챕터 간 직접 참조를 금지하고, 공유가 필요하면 `shared/` 로 올립니다.
